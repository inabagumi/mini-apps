# Haneru Beat!

「Haneru Beat!」は因幡はねるさんの鼓動を感じるためのアプリです。因幡はねるさんの鼓動を感じて、因幡はねるさんに包まれて眠りましょう。

## デプロイ

[Vercel](https://vercel.com/home)にデプロイすることを前提として開発されています。そのためVercel以外の環境へデプロイを行った際の動作については保証できません。
